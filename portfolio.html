CC3Policy debate

Making a case with data

Section 1: Should Brazil modernize its power grid? Renewables supply about 87% of its electricity, yet much wind and solar goes unused.

Since 2012, wind and solar grew from about 5,000 to over 200,000 GWh while hydropower stayed roughly flat. Variable sources drove most growth.

Clean Energy Left Unused

In 2025, Brazil curtailed about 37,200 GWh of wind and solar. Over half was oversupply; the rest came from grid limits and outages (ONS).

Curtailment shows the grid has become a bottleneck, unable to absorb surplus clean energy. Modernization needs new Northeast transmission, battery storage and flexible demand.

CC5Accessing data

API and scraper

Section 1: API

The data for this chart was extracted from the World Bank World Development Indicators (WDI) API. Starting from the base URL (https://api.worldbank.org/v2), I retrieved the data by adding the following elements: (1) the country code for Venezuela (VEN); (2) the indicator code that identifies the series, in this case GDP per capita in current US$ (NY.GDP.PCAP.CD); (3) the format in which the API returns the information (format=json); (4) the date range (date=1970:2025); and (5) the number of observations per page, so the API returns the whole selected period in one response (per_page=100).

The API URL for this chart returns the data in a tidy JSON format. The first section contains the metadata of the request, while the second contains the relevant data observations. Finally, I used Vega-Lite to prepare the data for the visualization.

Section 2: Scraper

Scraped Venezuela's electricity mix from Americas Quarterly. Challenge: data embedded as an Infogram iframe. I parsed its JSON and cleaned values into tidy format.

CC7Maps

Base maps and choropleths

As an extension of the Week 6 coding challenge, these interactive maps offer a comprehensive look at alcohol-specific death rates across the UK.

Both maps out data down to the local level, covering 296 local authorities in England, 32 council areas in Scotland, 22 local authorities in Wales, and 11 districts in Northern Ireland.

Section 1: Coordinates map

This coordinates map shows where the burden falls, which depends on how many people live in a place. A circle is placed at the latitude and longitude of the centre of every local area in the UK. The area of each circle is proportional to the average number of alcohol-specific deaths per year. To compare areas fairly, the deaths in each period are divided by the number of years it covers (five years for Scotland, three for the rest).

Section 2: Choropleth

This choropleth colours every local area by its rate of alcohol-specific deaths per 100,000 people.
